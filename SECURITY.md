# Security Policy

## Supported Version

Only the current `main` branch is supported.

## Report A Vulnerability

Do not open an issue for a suspected vulnerability or exposed secret. Send an
initial message with no vulnerability details to `agentic-coding@gsa.gov` and
request an approved private GSA reporting route. Share technical evidence only
after an authorized handler provides that route.

Include the affected revision, observed behavior, impact, and safe reproduction
steps. Do not include live credentials, controlled data, personal data, or
third-party data.

## Handling

Maintainers will acknowledge the report, assess severity, and coordinate a fix
and disclosure. Timelines depend on impact and verification needs.
